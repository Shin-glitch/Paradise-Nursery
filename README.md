# Paradise Nursery

A React-based plant shopping website built using React, Redux Toolkit, and React Router.

## Features

- Landing page with navigation
- Plant products organized by category
- Add plants to cart
- Dynamic cart item count
- Increase and decrease plant quantities
- Remove plants from cart
- Automatic total price calculation
- Continue Shopping functionality
- Checkout button with "Coming Soon" message
- Redux Toolkit for cart state management

## Pages

- Home
- Plants
- Cart

## Tech Stack

- React
- React Router
- Redux Toolkit
- React Redux
- Vite
- CSS
